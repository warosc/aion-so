# Visión de AION OS

## La pregunta

¿Cómo funcionaría una computadora si hubiera sido diseñada después de la IA, en lugar de antes?

AION OS convierte objetivos humanos en planes verificables y acciones autorizadas. No reemplaza la seguridad del sistema por decisiones probabilísticas: separa estrictamente la inteligencia del mecanismo.

## Experiencia objetivo

El usuario puede expresar una intención como:

> Organiza las fotografías de hoy en el proyecto Vacaciones, sin borrar originales.

El sistema debe resolverla mediante una secuencia visible y controlada:

1. Interpretar la intención.
2. Proponer un plan estructurado.
3. Resolver archivos y recursos sin modificarlos.
4. Solicitar únicamente las capacidades necesarias.
5. Mostrar confirmación cuando exista riesgo.
6. Ejecutar en un entorno aislado.
7. Verificar el resultado y registrar la acción.

## Qué es

- Un sistema operativo real, arrancable y progresivamente portable.
- Un kernel independiente de modelos de IA.
- Un runtime de agentes en espacio de usuario.
- Una shell tradicional que luego aceptará lenguaje natural.
- Un laboratorio para seguridad basada en capacidades.

## Qué no es

- Una distribución Linux renombrada.
- Un chatbot ejecutándose con privilegios de administrador.
- Un intento inicial de competir con Windows o Linux en cantidad de drivers.
- Un sistema cuya operación básica dependa de una API externa.

## Éxito de la primera etapa

AION v0.0.1 arranca repetidamente en QEMU con UEFI, inicializa una consola, recibe teclado y ejecuta comandos básicos sin red ni IA.
